# ScamShield — AI 사기문자·스미싱 위험도 판독 MVP

의심스러운 문자나 링크를 넣으면 **위험 신호를 쉽고 빠르게 설명해주는 AI 안전보조 서비스**입니다.
모바일 중심의 반응형 웹앱으로, 가입 없이 바로 사용할 수 있습니다.

> 이 서비스의 결과는 참고용 위험 신호 분석이며 실제 사기 여부를 확정하는 판정이 아닙니다.

## 주요 기능

- **문자 직접 입력 / 캡처 이미지 업로드** 두 가지 분석 플로우
- 단계별 **AI 분석 로딩** → **위험도 게이지(0~100)** → 위험 신호 카드
- **의심 문구 하이라이트** — 문구를 탭하면 "왜 의심스러운가요?" 설명
- **링크·연락처 분석** (단축 URL, 의심 도메인, 국제발신 번호 등)
- 고령 사용자도 읽기 쉬운 **AI 요약**과 **지금 해야 할 행동** 가이드
- **결과 공유** (Web Share API, 클립보드 폴백)
- **분석 기록** 저장 및 상세 재조회 (브라우저 로컬 저장, 원문 마스킹 미리보기)
- 유형별 **안전가이드** (금융·정부·택배·지인 사칭, 투자·대출 사기 등 8종)
- 접근성: **보통/큰/매우 큰 글자** 설정, 48px 터치 타깃, 하단 내비게이션

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Lucide Icons, Pretendard
- 배포: Vercel

## 시작하기

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다.

## 분석 엔진 구조

- `lib/risk-engine.ts` — **Demo Analysis Engine**. 긴급성·개인정보·금전·사칭·링크 키워드 규칙을
  조합해 위험도 점수와 신호를 생성합니다. (실제 금융사기 판정 알고리즘이 아닙니다.)
- `lib/ai.ts` — `analyzeMessage()` 등 분석 진입점. `AI_API_KEY` 환경변수가 설정되면
  `/api/analyze`에서 실제 LLM 호출로 교체할 수 있는 구조이며, 없으면 데모 엔진을 사용합니다.
- 이미지 업로드는 MVP에서 데모 추출 텍스트를 사용하며, OCR API를 연결하기 쉬운 구조입니다.

## Supabase

`supabase/schema.sql`에 users / analyses / risk_signals / safety_guides / saved_guides
테이블 스키마가 포함되어 있습니다. 환경변수가 없으면 로컬 저장소 기반 데모 모드로 동작합니다.

## 환경변수

`.env.example` 참고. 모든 값이 없어도 데모 모드로 완전히 동작합니다.
